## Normalized vector
- solve for length in x**2 + y**2 + z**2 = length**2, find square root of length**2
- (x/length)**2 + (y/length)**2 + (z/length)**2 = 1
- however, because we arent solving for the normalized length, the vector will return as x/length, y/length, z/length, no need to square it to my knowledge
- primary point is to conserve the direction of the vector and its components while removing magnitude/length
