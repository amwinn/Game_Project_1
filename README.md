A 2D tile-based game built purely in Vanilla JavaScript

## Purpose
Learn the fundamentals of programming in an engaging way

## Overview
I've always been interested in the full spectrum of game development, including the underlying systems themselves. I have worked on this project (my first) since the beginning of my programming journey, and have continuously refactored it as I acquire new concepts and skills, rather than starting new projects. This allows me to focus on criticalities such as refactoring, organization, architecture, scalability, and maintainability.


## Current Features
- Viewport camera
- Collision for both square and circle derived entities
- Nova, Projectile, and Radial ability types
- Modular ability system based on requirement, form, and effect
- Health, Damage, and Mana
- Movement implemented via Command Pattern
- Movement and ability animation
- Unique ID generation for items

## Nascent Features

- Droppable items
- Inventory
